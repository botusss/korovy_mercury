Автоматическое добавление животных из Excel в ИС «Хорриот» (Меркурий)
Этот скрипт полностью автоматизирует поиск и добавление животных из вашей таблицы Excel в информационную систему «Меркурий». Вам больше не нужно вручную искать каждую корову по номеру и кликать галочки — скрипт сделает это за вас.

🛠️ Часть 1. Подготовка (Установка расширения и скрипта)
Чтобы скрипт заработал, в вашем браузере должен быть установлен специальный помощник — Tampermonkey. 
> [!WARNING]
> **ВНИМАНИЕ!** [Полная инструкция по установке Tampermonkey и скрипта](#приложение-к-части-1-полная-пошаговая-установка-и-настройка-tampermonkey-и-скрипта) внизу. Читаем.

📂 Часть 2. Подготовка Excel-файла
Перед началом работы убедитесь, что ваш файл Excel оформлен правильно:

Файл должен быть в формате .xlsx или .xls.

Скрипт читает самый первый лист вашего Excel-файла.

На этом листе обязательно должны быть колонки с названиями:

**«Внутрихозяйственный номер»** (или просто «№» / «Номер») — по нему скрипт ищет животное.

**«Кличка»** — по ней скрипт проверяет, то ли это животное.

🚀 Часть 3. Как пользоваться скриптом
Зайдите на сайт Меркурия в нужный раздел 

В правой части экрана появится аккуратная панель управления «Хорриот ← Excel».

Нажмите кнопку «Выберите файл» на панели и укажите ваш подготовленный файл Excel с коровами.

Скрипт мгновенно прочитает файл и покажет количество найденных строк.

Нажмите кнопку «Старт».

Скрипт начнет автоматически по очереди вбивать номера, искать животных, ставить нужные галочки и добавлять их в опись.

📊 Дополнительные возможности панели:
Живой лог: В окошке внизу панели в реальном времени пишется статус по каждому животному (например, «Добавлено», «Уже в описи» или «Не найдено»).

Кнопка «Стоп»: Если вам нужно срочно прервать работу скрипта, просто нажмите эту кнопку.

Кнопка «Скачать лог»: По окончании работы скрипт автоматически (или по нажатию кнопки) сохранит на ваш компьютер Excel-файл с полным отчетом по каждой корова (что было добавлено, а где возникли ошибки).

 
 
### **ПРИЛОЖЕНИЕ К ЧАСТИ 1. ПОЛНАЯ ПОШАГОВАЯ УСТАНОВКА И НАСТРОЙКА Tampermonkey и скрипта.**
### Установка и настройка

#### 1. Установка Tampermonkey
Установите расширение **Tampermonkey** для вашего браузера:
* [Google Chrome / Яндекс Браузер / Brave](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
* [Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
* [Mozilla Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
* [Safari](https://apps.apple.com/app/tampermonkey/id1482490089)

#### 2. Разрешение пользовательских скриптов (для Chrome и Chromium-браузеров)
В современных версиях браузеров на базе Chromium без этого шага скрипты запускаться не будут:
1. Откройте страницу расширений, введя в адресную строку `chrome://extensions` (или нажмите на иконку пазла в правом верхнем углу → **Управление расширениями**).
2. Найдите карточку **Tampermonkey** и нажмите кнопку **Подробнее** (*Details*) или если нет это кнопки то кнопку **Сведения**.
3. Включите переключатель **Разрешить пользовательские скрипты** (*Allow User Scripts*) — в некоторых версиях вместо него используется **Режим разработчика** (*Developer mode*) в правом верхнем углу страницы расширений.

1. Откройте [прямую ссылку на файл скрипта c нашими коровами](https://github.com/botusss/korovy_mercury/raw/refs/heads/main/korovy_mercuryvetrfru.user.js) (`Raw` на GitHub).
