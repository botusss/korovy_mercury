Автоматическое добавление животных из Excel в ИС «Хорриот» (Меркурий)
Этот скрипт полностью автоматизирует поиск и добавление животных из вашей таблицы Excel в информационную систему «Хорриот» на портале ВЕТИС («Меркурий»). Вам больше не нужно вручную искать каждую корову по номеру и кликать галочки — скрипт сделает это за вас.

🛠️ Часть 1. Подготовка (Установка расширения)
Чтобы скрипт заработал, в вашем браузере должен быть установлен специальный помощник — Tampermonkey.

Откройте ваш браузер (Google Chrome, Яндекс.Браузер, Microsoft Edge или Firefox).

Зайдите в официальный магазин расширений вашего браузера (например, Интернет-магазин Chrome).

В строке поиска напишите Tampermonkey и нажмите поиск.

Найдите расширение с иконкой черного квадратика в виде головы в капюшоне и нажмите кнопку «Установить» (или «Получить»).

Подтвердите установку. После этого в правом верхнем углу экрана (возле адресной строки) появится значок Tampermonkey.

📥 Часть 2. Установка скрипта
Нажмите на этой странице GreasyFork кнопку «Установить скрипт» (Install).

У вас откроется новая вкладка с текстом программы.

Нажмите появившуюся красную или зеленую кнопку «Установить» (Install).

Готово! Скрипт успешно добавлен в ваш браузер.

📂 Часть 3. Подготовка Excel-файла
Перед началом работы убедитесь, что ваш файл Excel оформлен правильно:

Файл должен быть в формате .xlsx или .xls.

Скрипт читает самый первый лист вашего Excel-файла.

На этом листе обязательно должны быть колонки с названиями:

«Внутрихозяйственный номер» (или просто «№» / «Номер») — по нему скрипт ищет животное.

«Кличка» — по ней скрипт проверяет, то ли это животное.

🚀 Часть 4. Как пользоваться скриптом
Зайдите на сайт Меркурия в нужный раздел 

В правой части экрана появится аккуратная панель управления «Хорриот ← Excel».

Нажмите кнопку «Выберите файл» на панели и укажите ваш подготовленный файл Excel с коровами.

Скрипт мгновенно прочитает файл и покажет количество найденных строк.

Нажмите кнопку «Старт».

Скрипт начнет автоматически по очереди вбивать номера, искать животных, ставить нужные галочки и добавлять их в опись.

📊 Дополнительные возможности панели:
Живой лог: В окошке внизу панели в реальном времени пишется статус по каждому животному (например, «Добавлено», «Уже в описи» или «Не найдено»).

Кнопка «Стоп»: Если вам нужно срочно прервать работу скрипта, просто нажмите эту кнопку.

Кнопка «Скачать лог»: По окончании работы скрипт автоматически (или по нажатию кнопки) сохранит на ваш компьютер Excel-файл с полным отчетом по каждой корова (что было добавлено, а где возникли ошибки).
